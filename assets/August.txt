  - /metrics and /prometheus classified as medium debug endpoints

  - Kills timed-out child processes; optional quiet mode for probe spam

TRIAGE.PY — MANUAL FINDING VERIFICATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: sqlmap, dalfox, and nuclei findings still need a human to
confirm or mark false positive before client delivery. RedScanner had
no file format for that outcome.

Design: standalone script (like scan_diff.py) on finished report.json —
no results.db changes, no --resume interaction.

  python triage.py export output/<target>/<scan>/report.json
  # edit triage_template.json → status + note
  python triage.py apply  output/<target>/<scan>/report.json \
                           output/<target>/<scan>/triage_template.json

Outputs: report.verified.json, verification_summary.md
Finding key: sha1(url|type|parameter|evidence|tool)[:12]
