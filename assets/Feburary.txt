OWASP ZAP tool (very very recommend)
OWASP ZAP functions as a “man-in-the-middle” proxy, intercepting traffic between a browser and a web application. It can automatically scan for common vulnerabilities such as SQL injection, cross-site scripting (XSS), and insecure cookies. Users can also perform manual testing through built-in tools including fuzzers, spiders, and request editors.


Assetfinder https://github.com/tomnomnom/assetfinder.git
Assetfinder aggregates domain and subdomain data from multiple public sources and APIs. It supports quick enumeration by querying services like Certificate Transparency logs and online databases of known domains. The tool’s focus is speed and simplicity, allowing integration with other reconnaissance utilities such as amass, subfinder, and httprobe


sqlmap : https://github.com/sqlmapproject/sqlmap.git
result : SQLMap automates a broad set of SQL injection techniques, including boolean-based blind, time-based blind, error-based, UNION query-based, stacked queries, and out-of-band exploitation, Once vulnerabilities are detected, it can fingerprint database types and versions, enumerate users and tables, extract or modify stored data, and, when permitted, execute operating system commands on the host. It supports most major database engines such as MySQL, PostgreSQL, Oracle, Microsoft SQL Server, and SQLite.


dalfox : https://github.com/hahwul/dalfox.git
Dalfox supports multiple scanning modes—URL, file, pipeline, server, and payload generation—allowing use in diverse testing scenarios. It identifies reflected, stored, DOM-based, and blind XSS vulnerabilities, and performs parameter mining and static analysis. Features such as bad character filtering, payload abstraction, and parallel encoding optimize performance while reducing noise. The tool also detects issues like open redirects, SSTI, and SQL injection in its extended analysis modes
