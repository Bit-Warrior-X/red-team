Day 2:
RedScanner v0.2 — HTTP security header scanner
Implemented modules/header_scanner.py using curl HEAD (-I). Missing-header checks: HSTS, CSP, X-Content-Type-Options, X-Frame-Options, Referrer-Policy, Permissions-Policy, X-XSS-Protection. Disclosure checks: Server, X-Powered-By, X-AspNet-Version. Set-Cookie checks: Secure, HttpOnly, SameSite. Mapped to OWASP WSTG-CONF-07 and WSTG-CONF-05.

Results:
- HeaderScanner with _fetch_headers() and _check_cookies(); findings in standard vulnerability tables (tool header_scanner).
- No extra install beyond curl.

Analysis:
- Fills configuration gaps when nuclei/nikto return few hardening items on the lab host.
