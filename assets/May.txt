RedScanner v0.2 — New Features (May)

HTTP Security Header Scanner (header_check module)
module : modules/header_scanner.py
Added a new module that audits HTTP response security headers using curl HEAD requests.
Checks for missing security headers: HSTS, Content-Security-Policy, X-Content-Type-Options,
X-Frame-Options, Referrer-Policy, Permissions-Policy, X-XSS-Protection.
Checks for information disclosure headers: Server, X-Powered-By, X-AspNet-Version.
Checks for insecure cookie flags: Secure, HttpOnly, SameSite.
Mapped to OWASP WSTG-CONF-07 and WSTG-CONF-05.
New profiles added: header-only (recon + header_check only), header-only quick audit without vuln scanning.
No extra tool installation needed beyond curl.
Usage: python main.py --profile header-only

Enhanced XSS Scanner (dalfox)
module : modules/xss_scanner.py
Updated dalfox integration to use file mode (dalfox file <url_list>).
Feeds parameterized crawled URLs (URLs with query strings) to dalfox in bulk.
Dramatically increases XSS test surface when the crawler finds pages with query parameters.
Previously only tested single-URL per target; now tests all parameterized URLs found by xcrawl3r.

Nuclei Template Tag Control
config : assets/red_plan.json
Added nuclei_tags and nuclei_exclude_tags keys to red_plan.json for template filtering without editing code.
nuclei_tags: ["cve","oast","tech"] → only run templates with these tags.
nuclei_exclude_tags: ["dos","fuzz"] → skip templates that could disrupt the target.
Works alongside existing nuclei_extra_args for full flexibility.
Safe by default: dos and fuzz templates can now be explicitly excluded.

Scan Diff Tool
script : scan_diff.py
New standalone utility to compare two RedScanner JSON reports.
Shows new findings, resolved findings, unchanged findings, and surface changes (domains, ports, crawled URLs).
Identifies regression between scan runs on the same target.
Outputs to terminal (text) or JSON file (--output diff.json).
Usage: python scan_diff.py output/.../old/report.json output/.../new/report.json
